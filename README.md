# To-Do List

A responsive, browser-based to-do application built with HTML, CSS, and JavaScript.

## Features

- Add tasks
- Mark tasks as complete or active
- Delete tasks
- Filter tasks by All, Active, or Completed
- Automatically save tasks in local storage
- Responsive mobile-friendly layout

## Run locally

Open `index.html` in a browser, or serve the repository with a local HTTP server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
