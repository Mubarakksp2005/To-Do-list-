# To-Do List

A responsive, browser-based task manager built with HTML, CSS, and JavaScript.

## Features

- Add, complete, and delete tasks
- Persist tasks and theme preference with local storage
- Filter by all, active, or completed tasks
- Search tasks by name
- Sort by newest, oldest, alphabetical, or completion status
- Responsive layout and dark mode

## Run locally

Open `index.html` in a browser, or serve the repository:

```bash
python3 -m http.server 8000
```

Visit `http://localhost:8000`.
